# Changelog

## v0.3.0 — Initial public release (May 2026)

First public release of Tandem. Provides three modules:

- **Module 1**: Tandem duplication detection in reference genomes via NUCmer self-alignment, with HR-vs-non-HR mechanism classification.
- **Module 2**: Junction discovery in isolate sequencing data, with two-step coverage-guided workflow.
- **Module 3**: Population-level junction frequency quantification (Junction Read Ratio).

Validated on 8 reference genomes, 5 SBW25 experimental evolution isolates, and 240 artificial population tests across 6 bacterial species (100% recall, 4.3% mean absolute error).
